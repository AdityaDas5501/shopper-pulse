# 🛒 ShopperPulse: Unsupervised Customer Segmentation

An end-to-end Machine Learning project utilizing **Principal Component Analysis (PCA)**, **K-Means**, and **Agglomerative Hierarchical Clustering** to segment e-commerce customers into actionable buyer personas based on spending behavior, tenure, and demographic profiles.

---

## 📌 Project Overview
**ShopperPulse** analyzes customer transaction patterns to identify distinct purchasing cohorts. By translating raw retail data into data-driven buyer personas, marketing teams can optimize campaign strategies, tailor loyalty programs, and increase conversion rates.

---

## 🛠️ Data Pipeline & Methodology

1. **Preprocessing & Feature Engineering:**
   - Imputed missing `Income` values using median strategies.
   - Derived engineered metrics: `Age`, `Customer_Tenure_Period`, `Total_Spending`, and `Total_Children`.
   - Categorized education levels and consolidated marital status (`Living_With`).
   - Filtered age and income outliers to prevent skewness in distance metrics.

2. **Dimensionality Reduction:**
   - Standardized features using `StandardScaler`.
   - Applied **PCA** to reduce high-dimensional feature space down to 3 principal components while preserving maximum variance.

3. **Clustering & Model Evaluation:**
   - Evaluated optimal $K$ selection via **Elbow Method (WCSS)** and **Silhouette Scoring**.
   - Implemented and evaluated **K-Means Clustering** and **Agglomerative Hierarchical Clustering** ($K=4$).

## 📊 Customer Personas & Business Insights

Analysis of the 4 cluster profiles generated by Agglomerative Clustering:

| Cluster | Profile Name | Key Characteristics | Strategic Recommendation |
| :--- | :--- | :--- | :--- |
| **C0** | **Premium VIPs** | High Income, High Spending, Older, Low Web Visits, High Catalog/Store Purchases | High ROI segment. Target with premium product launches, VIP support, and concierge services. |
| **C1** | **Family Shoppers** | Moderate Income, Higher Number of Children, High Web Browsing, Moderate Spending | Focus on budget-friendly bundles, family discount coupons, and value messaging. |
| **C2** | **Budget Browsers** | Low Income, High Web Activity, Lowest Conversion Rate | Engage with automated abandoned-cart incentives, flash sales, and steep discounts. |
| **C3** | **Profitable Loyalty** | High Income, High Spending, Partnered, Low Web Visits | Retain through tier-based loyalty rewards, cross-selling, and subscription perks. |
